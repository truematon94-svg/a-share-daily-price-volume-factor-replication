# A股日频量价选股因子复现与策略优化

基于华泰证券《多因子系列之四：华泰单因子测试之动量类因子》（2016-12-20），使用聚宽日频数据复现A股动量/反转因子的完整研究链条，包括历史截面面板、单因子检验、分层回测、因子合成、纯多头策略和样本外检验。

项目不仅验证了原研报在2005—2016年样本内的主要结论，也检验了因子在2017—2024年的持续性，并针对失效现象进行了股票池约束与信号方向调整。最终优化使样本外策略年化收益由负转正，但仍未恢复相对基准的稳定超额收益。

## 研究结论

- A股1—12个月历史收益在原样本内均表现为反转，且短期反转最强。
- `return_1m` 的IR为 **0.637**，与研报的 **0.63** 基本一致。
- `return_1m` 五组分层多空年化超额为 **23.18%**，研报为 **26.18%**，方向、单调性和量级一致。
- WLS回归中的因子收益率序列t值为 **-5.24**，研报为 **-5.00**。
- 最大化IC_IR合成的前10%多头简单年化为 **20.30%**，优于等权合成的 **18.97%**。
- 聚宽交易回测中，样本内 `return_1m` 前10%纯多头策略年化收益为 **29.36%**，但最大回撤达到 **64.20%**。
- 2017—2024年，原反转策略样本外年化降至 **-3.12%**，显示因子发生显著衰减。
- 优化策略将股票池限制为中证800，并把信号从“买跌最多”改为“买涨最多”；中证800内策略年化由 **-4.05%** 提升至 **+1.08%**，改善 **5.13个百分点**并由负转正。

## 复现对象与范围

主复现对象为华泰动量类因子研究。项目实际实现以下12个核心因子：

| 因子类型 | 因子 |
|---|---|
| 简单累计收益 | `return_1m`、`return_3m`、`return_6m`、`return_12m` |
| 换手率加权收益 | `wgt_return_1m`、`wgt_return_3m`、`wgt_return_6m`、`wgt_return_12m` |
| 指数衰减换手率加权收益 | `exp_wgt_return_1m`、`exp_wgt_return_3m`、`exp_wgt_return_6m`、`exp_wgt_return_12m` |

研报中的 `HAlpha` 未纳入本项目最终实证结果，因此不将其计入已完成因子数量。

## 研究设计

| 项目 | 口径 |
|---|---|
| 数据源 | 聚宽A股日频行情、市值、行业与交易状态数据 |
| 原样本 | 2005-04-29—2016-11-30 |
| 样本外 | 2017-01-01—2024-12-31 |
| 股票池 | 历史时点全A股；优化策略使用历史中证800成分股 |
| 基准 | 沪深300 `000300.XSHG` |
| 截面频率 | 每月最后一个交易日 |
| 收益标签 | 下一自然月个股收益相对沪深300的超额收益 |
| 复权方式 | 聚宽前复权；用于收益计算时与研报后复权口径等价 |
| 样本过滤 | 剔除ST/PT及下期停牌股票 |
| 预处理 | 中位数±5×MAD去极值、Z-score标准化、行业与市值中性化 |
| 单因子检验 | IC/IR、胜率、WLS因子收益率、五组/十组分层 |
| 因子合成 | 等权合成、最大化IC_IR合成 |
| 交易检验 | 月频等权纯多头、手续费与不可交易约束 |

历史股票池和行业、市值数据均按截面日期获取，收益标签严格后移，避免使用当前成分股回填历史或把未来信息用于当期选股。

## 关键结果

### 1. 简单收益因子的IC表现

| 因子 | IC均值 | IC标准差 | IR | IC>0占比 |
|---|---:|---:|---:|---:|
| `return_1m` | -7.00% | 10.99% | 0.637 | 27.9% |
| `return_3m` | -6.03% | 11.96% | 0.504 | 29.3% |
| `return_6m` | -4.77% | 11.32% | 0.421 | 35.0% |
| `return_12m` | -4.14% | 11.58% | 0.357 | 35.1% |

IC均值全部为负，说明过去收益越低的股票下一期表现越好；随着观察窗口延长，反转效应逐渐减弱。

### 2. 五组行业中性分层

| 因子 | 组1 | 组2 | 组3 | 组4 | 组5 | 多空年化 |
|---|---:|---:|---:|---:|---:|---:|
| `return_1m` | 19.46% | 18.63% | 15.60% | 9.30% | -3.73% | 23.18% |
| `return_3m` | 20.92% | 17.01% | 15.33% | 8.59% | -1.57% | 22.49% |
| `return_6m` | 20.55% | 18.41% | 14.57% | 10.04% | 0.02% | 20.53% |
| `return_12m` | 19.71% | 17.73% | 14.61% | 9.43% | 1.88% | 17.83% |

组1为历史收益最低的反转多头，四个因子均呈现严格的分层单调性。

### 3. 因子合成

| 合成方法 | 前10%多头简单年化 |
|---|---:|
| 等权 | 18.97% |
| 最大化IC_IR | 20.30% |

最大化IC_IR方法使用因子IC均值和IC协方差矩阵确定非负权重，并对协方差矩阵进行收缩处理，以降低权重对样本噪声的敏感性。

### 4. 样本外失效与策略优化

| 版本 | 股票池 | 信号 | 策略年化 | 相对基准超额 |
|---|---|---|---:|---:|
| 原始反转 | 全A股 | 买入过去跌幅最大股票 | -3.12% | -38.60% |
| 市值约束 | 中证800 | 买入过去跌幅最大股票 | -4.05% | -44.01% |
| 方向优化 | 中证800 | 买入过去涨幅最大股票 | +1.08% | -7.95% |

优化过程采用递进假设检验：

1. 先用中证800排除“小盘壳价值消失导致反转失效”的解释；反转策略表现没有改善，说明单纯限制市值并不能解决问题。
2. 再将信号从反转切换为动量，策略年化改善5.13个百分点并由负转正，说明2017年后的市场结构更有利于中大盘股票的动量延续。
3. 优化后仍跑输基准，因此本项目将其记录为“显著改善但未恢复稳定Alpha”，而不是将参数调整包装成成功策略。

## 与原研报的口径差异

| 项目 | 华泰研报 | 本项目 |
|---|---|---|
| 数据源 | Wind | 聚宽 |
| 复权 | 后复权 | 前复权 |
| 行业分类 | 中信一级 | 申万一级 |
| 换手率 | Wind换手率字段 | 根据聚宽成交量和流通市值构造 |
| 分层行业权重 | 沪深300行业权重 | 行业内分组、跨行业等权 |

这些差异对简单收益因子的影响较小，但会影响换手率加权因子的增强幅度，因此项目重点复现经济方向、分层单调性和统计量级，不声称逐项数值完全一致。

## 运行顺序

聚宽研究环境负责原始行情、市值和行业数据获取，本地Python环境负责统计检验、因子合成与结果汇总，聚宽回测环境负责交易策略验证。

1. 在聚宽研究环境运行 `notebooks/01_data_pipeline/step1_build_monthly_panel.py`。
2. 将生成的月频面板保存到本地 `data/processed/`。
3. 运行 `step2_build_improved_factors.py` 构建换手率加权与指数衰减因子。
4. 依次运行 `notebooks/02_single_factor_tests/` 下的IC、分层和WLS检验脚本。
5. 运行 `notebooks/03_factor_combination/` 下的相关性与因子合成脚本。
6. 在聚宽回测环境运行 `backtest/` 中的样本内策略和样本外优化策略。

安装本地依赖：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

原始行情、授权数据、研报PDF和中间面板不进入Git仓库。公开仓库只保存研究规格、实现代码、结果摘要与可复核的运行路径。

## 局限性

- 数据源和行业分类与原研报不同，换手率加权因子无法做到逐值一致。
- 行业中性分层采用跨行业等权，未完全复刻沪深300行业权重。
- 样本内纯多头策略最大回撤较高，不能仅依据年化收益判断策略可交易性。
- 样本外优化策略虽然由负转正，但仍未取得正超额收益，说明简单量价信号存在明显的时代依赖性。
